PUBLISH ON GITHUB PAGES
1. Create or open your GitHub repository.
2. Upload ALL FOUR files to the repository root (not inside another folder):
   index.html, style.css, script.js, README.txt
3. Commit the uploaded files to the main branch.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Choose branch "main" and folder "/ (root)", then Save.
7. Wait for GitHub Pages to publish, then open the website URL shown in Pages.
